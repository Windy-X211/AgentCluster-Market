# 进度邮件模板（email-template.md）

> 智能体按场景选用对应模板，填充变量后作为邮件正文发送。发送前把 Markdown 符号
> （如 `**`、`-`）转成易读的纯文本或保留为带空行的纯文本，避免邮件里出现裸符号。
> 主题统一加前缀：`【进度】` / `【定时汇报】` / `【完成】`。

---

## 一、分阶段汇报模板

**主题**：`【进度】{阶段名} 已完成 ({当前阶段序号}/{总阶段数})`

**正文**：

```
你好，这是你交给 AgentCluster 的任务「{任务名}」的阶段性进度汇报。

【当前阶段】{阶段名}（第 {当前阶段序号}/{总阶段数} 个阶段）—— 已完成
【已用时间】约 {已用时间}
【进度】{当前阶段序号}/{总阶段数}（{百分比}%）

本阶段完成情况：
{本阶段完成说明，2-4 句}

下一步：
{下一阶段名 + 预计内容，1-2 句}

如需查看完整对话记录，请回到 AgentCluster。

—— AgentCluster 进度邮件通知
```

---

## 二、定时汇报模板

**主题**：`【定时汇报】{任务名} {当前时间 HH:MM}（进度 {百分比}%）`

**正文**：

```
你好，这是任务「{任务名}」的定时进度汇报。

【时间】{当前时间 YYYY-MM-DD HH:MM}
【进度】{已完成数}/{总数}（{百分比}%）
【当前步骤】{正在做什么，一句话}
【已用时间】{已用时间}
【异常/提示】{有异常写异常，无异常写"一切正常，无异常"}

本封邮件为自动定时汇报，任务完成或你喊停后即停止。

—— AgentCluster 进度邮件通知
```

---

## 三、任务完成通知模板

**主题**：`【完成】{任务名} 已完成`

**正文**：

```
你好，你交给 AgentCluster 的任务「{任务名}」已全部完成。

【总耗时】{总耗时}
【完成项】{完成数量} 项
  - {完成项1}
  - {完成项2}
  - ...
【产出位置】{文件路径 / 链接}
【失败项】{失败数量} 项（如有）
  - {失败项 + 原因，无则写"无"}

总结：
{2-4 句任务总结}

如需查看完整对话记录或产出，请回到 AgentCluster。

—— AgentCluster 进度邮件通知
```

---

## 使用约定

- 变量用 `{}` 包裹，智能体填入实际值时**去掉花括号**。
- 时间格式统一 `YYYY-MM-DD HH:MM`；耗时用 `X 时 Y 分` 或 `X 分 Y 秒`。
- 百分比取整数（`45%`），不要小数。
- 若某段无内容（如"失败项"为空），写"无"而非留空。
- 语言跟随用户语言；默认简体中文。
- 涉及敏感文件内容/内部数据时，先征得用户同意再写入正文。
